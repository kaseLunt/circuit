# Project north star

A publicly deployed, provably-correct node-based DeFi strategy composer that demonstrates
disciplined web3 frontend / design engineering — compelling to a cold expert reader in 3 minutes,
defensible under 20 minutes of adversarial reading.

## Success evidence

- The SPEC §3 demo script passes on the production URL, verified by the scheduled smoke — not by
  assertion.
- The pinned-fork suite executes the full 13-step flagship plan green in CI, with HF asserted
  against Aave after every risk-changing step.
- A cold reviewer can trace any number on screen to its provenance (Observed / Derived / Entered /
  Configured) from the UI itself.
- Zero instances of the failure classes this project exists to avoid: fabricated values, dead
  subsystems, unfinished flagship surfaces.

## Boundaries

- Not a product; no growth/TVL/revenue claims. The audience is one cold expert reader.
- Scope is SPEC v1 + the P5 list; anything else requires a ratified Decision first.
- Claims never exceed shipped reality — if scope is cut, the story is cut with it.
